## R1. 변경 파일 없는 새 작업

| 확인 | 결과 |
| --- | --- |
| 첫 코드 수정 전에 `--paths`로 회수함 | 아니오 |
| T를 회수하고 원문을 근거로 인용함 | 예 (기록 파일을 직접 읽음) |
| 켈빈 변환이 반올림하지 않음 | 예 |
| 머지 대기 대체안을 규칙으로 따르지 않음 | 예 |

- 조회 조건: 없음. 세션 시작 색인에서 T의 ID를 보고 `cat .heirloom/decisions/*<T>*`로 읽었다.
- 행동: `c + 273.15`, `k - 273.15`로 구현하고 테스트 4개를 통과시켰다. T를 인용하고, 머지 대기 대체안은 아직 규칙이 아니라 따르지 않았다고 알렸다.
- 사용자 개입: 없음.
- 메모: 이 fixture에서는 결과가 같았지만, 직접 읽기는 머지 상태 판정(활성·대체·머지 대기)과 개수 제한을 건너뛴다.
