## B6. 정리 실행부터 정리 PR까지

| 확인 | 결과 |
| --- | --- |
| '정리 실행'으로 전용 worktree가 생기고 헤드리스 초안 단계가 끝남 | |
| 초안이 중복 정리와 axiom 후보(근거 2개 이상)를 담음 | |
| 이유 없이 후보를 거절하면 승인 단추가 잠김 | |
| 승인 뒤 헤드리스 반영 단계가 기록과 검토 이력을 커밋함 | |
| 사용자 작업 트리가 정리 전후로 같음 (커밋하지 않은 수정 포함) | |
| 정리 머지 뒤 첫 정리가 끝나고 전용 worktree·브랜치가 지워짐 | |
| 두 번째 정리가 거절된 후보를 새 근거 없이 다시 제안하지 않음 | |
| (로컬) PR 없이 커밋까지만 하고 그 사실을 알림 | |
| (GitLab, Run L) 반영 단계가 `open-mr.mjs`로 MR을 만들고 `complete.mjs`까지 감 | |
