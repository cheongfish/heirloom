# 지원 예정

[English](../en/roadmap.md)

다음 기능은 아직 지원하지 않으며, 이후 버전에서 지원할 예정입니다. 일정과 범위는 바뀔 수 있습니다.

| 기능 | 현재 동작 |
| --- | --- |
| 관련 기록 원문 조회(`recall-context`) | 세션 시작 때 decision 색인만 제공합니다. |
| 머지 여부에 따른 기록의 활성·대기 판정 | 작업 트리의 기록 파일을 기준으로 보여 줍니다. |
| Codex, Antigravity 호스트 | Claude Code만 지원합니다. |
| GitLab(`glab`)과 github.com 이외의 원격 | 기록 파일까지만 쓰고 PR은 직접 만들어야 합니다. |
| 승인 이후 증분 재확인 | 승인 뒤 코드가 조금이라도 바뀌면 전체를 다시 인계해야 합니다. 이전 승인은 보존됩니다. |
| 별도 맥락 정리와 axiom 후보 생성 | 에이전트가 초안에 제안한 axiom 변경만 승인받습니다. |
| Windows 키체인 | 개인키를 파일(0600)로 보관합니다. |
