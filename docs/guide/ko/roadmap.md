# 지원 예정

[English](../en/roadmap.md)

다음 기능은 아직 지원하지 않으며, 이후 버전에서 지원할 예정입니다. 일정과 범위는 바뀔 수 있습니다.

| 기능 | 현재 동작 |
| --- | --- |
| Codex, Antigravity 호스트 | Claude Code만 지원합니다. |
| GitLab(`glab`)과 github.com 이외의 원격 | 기록 파일까지만 쓰고 PR은 직접 만들어야 합니다. [맥락 정리](curation.md)는 worktree에 기록을 커밋하는 데까지 하고, 브랜치 push와 머지는 직접 해야 합니다. |
| Codex·Antigravity로 헤드리스 정리 | 정리는 Claude Code로만 실행합니다(`curation.agent.host`). |
| Windows 키체인 | 개인키를 파일(0600)로 보관합니다. |
